# Roadmap

Near-term items, ordered by value. All are in active development. This page states direction, not dates or commitments.

1. **Production billing activation** — goes live after a full rehearsal of balance, pricing, settlement, and spend-cap flows.
2. **Reproducible public memory benchmarks** — participation and published results on public memory benchmarks such as AMB.
3. **Cross-language recall enhancement** — for example, a Chinese query directly hitting an English memory — and a near-production re-anchor of the nano embedding stack.
4. **Graph-aware writes and temporal diffusion recall**, plus cross-encoder (CE) reranking.
5. **Local Proxy 0.1.2** — bringing tool-output removal to the local path.
6. **Distribution channels** — the official MCP servers list, Smithery, PulseMCP, and Glama.
7. **Manual pin API** — promoting key memories from the quarantine ring directly into the main memory layer.

For what already shipped, see the [changelog](changelog.html).
