# Roadmap

Near-term items, ordered by value. All are in active development. This page states direction, not dates or commitments.

1. **Reproducible public memory benchmarks** — participation and published results on public memory benchmarks such as AMB.
2. **Cross-language recall enhancement** — for example, a Chinese query directly hitting an English memory — and a near-production re-anchor of the nano embedding stack.
3. **Graph-aware writes and temporal diffusion recall**, plus cross-encoder (CE) reranking.
4. **Distribution channels** — the official MCP servers list, Smithery, PulseMCP, and Glama.
5. **Manual pin API** — promoting key memories from the quarantine ring directly into the main memory layer.

For what already shipped, see the [changelog](changelog.html).
